# DIWAN Android

<!-- impeccable:product-schema 1 -->

## Platform

Web presentation inside an Android-only Java/WebView application. The Android wrapper supplies selected-folder access, local file writes, backup verification and printing. Browser captures test the presentation; they are not Android device screenshots.

## Users and jobs

The user prioritizes daily transactions and quick entry, and explicitly considers accounts and balances important. DIWAN users open their own local finance documents, record and review money movements, check balances, and plan budgets.

## Product truth

The financial engine is DIWAN 1.2.12. Android finance-file opening supports only `.diwan` and `.mmb`. Preserve existing financial calculations, transfers, split transactions, currency rules, document formats and preference storage. Document saving is explicit; preferences use the original queued autosave.

## Mobile commitment

The user requested a mobile approach and design substantially different from web/Windows, based on the 26 supplied Android screenshots of Money Manager Ex and Bluecoins. Activity and quick entry lead. Accounts remain a main destination. The mobile navigation, account list, timeline, details, budget summary and entry form are authored separately from the desktop presentation.
