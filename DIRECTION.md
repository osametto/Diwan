# Android direction: an everyday pocket ledger

Mode: Operate. The user's competitor-like direction is pinned: the supplied screenshots govern the interaction vocabulary. The exploratory seed's generated assignment is subordinate to this explicit brief; no alternate aesthetic or image comp is being substituted. This is a code-led redesign of a WebView frontend.

## First viewport

A compact app bar identifies the active account or Transactions, with the file accessible below it and save/search actions alongside. Account and period selectors sit above transaction-type tabs. Date groups divide a dense timeline. Each row separates payee/category/notes from amount/currency/account. A single Add action sits above five main destinations: Activity, Overview, Accounts, Budget and More.

## Signature interaction

Tap an account balance to move directly into its register, including incoming transfers. Tap a transaction for a dedicated detail screen; edit through a full-screen amount-first form with Expense/Income/Transfer controls. Cross-currency transfer details keep the sent and received amounts explicit.

## Cross-surface reach

Accounts are grouped flat lists with native currencies and a separately labeled converted total. The budget shows one month of real envelope groups and in-place allocation sheets. Overview summarizes existing engine values. More retains real secondary tools in a single task area without desktop navigation chrome. A rail replaces the bottom bar on expanded width.

## Material choices

Platform sans typography, cobalt primary actions, white and blue-gray light surfaces, dark ink surfaces at night, restrained coral debit and green credit semantics. One consistent authored SVG stroke set. No competitor artwork, sample balances or APK code is copied into the app.

## Risks and evidence

Some secondary tools still render the original engine's forms in a mobile task container; this is documented rather than presented as a rewritten financial engine. Browser UI evidence uses synthetic data. Android device navigation, IME, printing and SAF providers need physical-device testing. The source-only deliverable contains no compiled APK.
